# Claude Code Instructions

Read and follow these repository files:

- `AGENTS.md`
- `PROJECT_DECISIONS.md`
- `PROJECT_ROADMAP.md`
- `CURRENT_PHASE.md`
- `docs/assignment-requirements.md`
- `docs/skill-routing.md`

## Claude-specific workflow

Before changing code:

1. Inspect available skills and follow `docs/skill-routing.md`.
2. State which matching skills will be used and why, or state that no suitable skill is available.
3. Inspect the repository.
4. Inspect `git status`.
5. Explain the current phase.
6. List proposed files and commands.
7. Wait for approval.
8. Implement only the scope in `CURRENT_PHASE.md`.
9. Run verification.
10. Stop after the current phase.

Do not rely on Claude plan files stored outside this repository.

The repository Markdown files are the source of truth.
