## Claude-specific workflow

Before changing code:

1. Inspect the repository.
2. Inspect `git status`.
3. Explain the current phase.
4. List proposed files and commands.
5. Wait for approval.
6. Implement only the scope in `CURRENT_PHASE.md`.
7. Run verification.
8. Stop after the current phase.

Do not rely on Claude plan files stored outside this repository.

The repository Markdown files are the source of truth.
